Limitations

  • Requires a Chromium browser with getDisplayMedia.
  • Capture includes whatever is on screen (controls, letterboxing, DPI scale).
  • At most six stills; the MediaStream is stopped when sampling ends.
  • This spike never downloads YouTube bytes or uses the Data API for media.
