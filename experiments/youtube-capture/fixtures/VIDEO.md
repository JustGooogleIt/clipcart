# Source video policy

Use a YouTube URL the team **owns** or has **permission** to analyze.

| Purpose | Suggested URL | Notes |
| --- | --- | --- |
| Wiring / player + capture UI | `https://www.youtube.com/watch?v=aqz-KE-bpKQ` (Big Buck Bunny, Creative Commons) | Not fashion — use for share/timestamp plumbing only |
| Garment proof | Team-owned fashion clip (paste into the spike UI) | Required for a meaningful Mk1.5 jacket/top/bag box |

This spike never downloads YouTube media. Frames come only from user-approved `getDisplayMedia` of the visible tab.
